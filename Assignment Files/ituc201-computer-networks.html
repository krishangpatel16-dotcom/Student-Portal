Fundamentals of Computer Networks

Questions

  1. Compare the OSI and TCP/IP reference models and map their main layers.
  2. Explain the difference between a MAC address and an IP address.
  3. Describe what happens when a browser resolves a domain name using DNS.
  4. Compare TCP and UDP in terms of reliability, ordering, overhead, and typical use.
  5. Given IPv4 address 192.168.10.25/24, identify the network address and the number of usable host addresses.
  6. Explain the purpose of a default gateway and when a host uses it.
  7. Describe how a switch learns MAC addresses and forwards an Ethernet frame.
  8. Compare HTTP and HTTPS and explain the role of TLS in protecting a connection.
  9. Draw a small campus network containing a router, switch, wireless access point, server, and three client devices.
  10. Explain packet loss and latency, and name one method for diagnosing each on a local network.
