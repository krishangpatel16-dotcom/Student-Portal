CEUE203 · Assignment 1

Object-Oriented Programming

Answer all ten questions. Use a consistent object-oriented language for code examples and justify design decisions.

Questions10
Suggested marks50
SubmissionWritten / PDF

Questions

  1. Define a class and an object. Give an example of each using a university course.
  2. Explain encapsulation and demonstrate it with private fields and public methods.
  3. Compare method overloading and method overriding, including one example of each.
  4. What is inheritance? Draw a small class hierarchy for a person, student, and instructor.
  5. Explain polymorphism and show how one interface can have two different implementations.
  6. Design a BankAccount class with a balance, a deposit method, and a withdrawal method that rejects invalid withdrawals.
  7. What is a constructor? Explain constructor overloading and when it is useful.
  8. Compare an abstract class with an interface. Give one situation suited to each.
  9. Describe exception handling and write a short example that catches an invalid numeric input.
  10. Identify two benefits and two risks of using inheritance in a large software system.

Submission note: This is a sample practice assignment. Include your name, student ID, course, and workings with your submission.
