Questions

  1. Write a Python program that reads a student's name and prints a personalized greeting.
  2. Explain the difference between an integer, a float, a string, and a Boolean value.
  3. Write a program that determines whether an entered integer is even or odd.
  4. Use a loop to calculate the sum of all integers from 1 through 100.
  5. Write a function that accepts a list of numbers and returns the largest value without using max().
  6. Given a sentence, count and print the number of vowels in it.
  7. Explain how lists and tuples differ, and give a suitable use case for each.
  8. Write a program that counts the frequency of each word in a sentence using a dictionary.
  9. Use a try/except block to handle a user entering text instead of a number.
  10. Write a program that reads a text file and prints the number of lines, words, and characters.
